A grid of images taller than the viewer, with the top row marked "A". fitHorizontally() fits the grid to the viewer's width but keeps it centred vertically, so the top and bottom rows are cut off. Galleries and multi-page documents usually want to start at the top instead (see #839).

On open, the demo calls fitHorizontally(true), reads the height of the visible area with getBounds(true), then pans so the top of that area meets the top of the grid. The home button still shows the whole grid.
