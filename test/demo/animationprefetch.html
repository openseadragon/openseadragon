Tile loading during animations: look-ahead vs. destination only

Each viewer opens the same synthetic layers through its own simulated network (see the tile load scheduler demo for the model) and plays the same animation at the same moment. While it animates, the view is sampled every frame on a grid: for each point and layer, how many pyramid levels the best tile drawn there is below the level the current zoom calls for (resolution deficit), and whether anything is drawn there at all (blank). The animation is considered arrived once the view is within 2% of a viewport of its destination and within 5% of its zoom; from then on the user is looking at the destination.
A: _loadPlanner: 'lookahead' (loads along the way when the destination can still be finished before arrival). B: _loadPlanner: 'destination' (destination only while animating). C (optional): look-ahead with the frame-paced loader (serverProtocol: false). Lower is better everywhere; within a scenario the best value is green, the worst red.
